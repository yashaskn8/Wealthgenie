# WealthGenie research-paper evidence and submission gate

**Scope:** Implemented evidence-aware, deterministic-constraint financial decision-support *prototype*. This ledger is not a commercial-data reuse approval or proof of production readiness.

## Reproducibility

1. Freeze a Git commit SHA. Archive Python/Node lockfiles, exact model revision, dataset identifiers and seeds.
2. Run the independent evidence audit (no new scores generated):
   python scripts/research/validate_paper_evidence.py --output paper-audit.json
3. Install the locked Python dependencies and the exact pinned sentence-transformer revision from ml-service/rag/embeddings/dense_embedding.py. From ml-service/, execute:
   python -m rag.evaluation.paper_replay --output reports/paper_rag_current.json
4. The replay constructs a **new temporary index** from hash-verified current corpus documents, forbids silent lexical-model fallback, evaluates the **current** five-question set, and saves question/corpus/model identities alongside observations. It never overwrites the historical 75-query artifact.
5. Validate actual results:
   python scripts/research/validate_paper_evidence.py --candidate ml-service/reports/paper_rag_current.json --output paper-audit.json
6. The --strict option intentionally fails until genuine external/generalization and rights prerequisites have been resolved. Retain the generated audit and benchmark CI artifacts alongside the commit hash.
7. Independently adjudicate factual labels and obtain necessary source reproduction approvals before submission.

### Work that cannot be manufactured by software

An independently labeled and adjudicated evaluation dataset with a wider corpus, prespecified hypothesis and baselines, repeated-seed analysis where applicable, uncertainty estimates, error analysis, complete environment/lineage, permission review for publication, and actual independent validation. With five questions, every percentage is statistically unstable.
